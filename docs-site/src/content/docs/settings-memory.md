控制每轮交给 GM 的存档记忆：每类记忆取多少条、总量上限多少 token、自动事实保留多久，以及三个记忆桶各自的开关和固定记忆的条数上限。调整这些参数可以在 GM 记得多少、每轮上下文费用之间取平衡。

入口：顶栏「设置」→ 左侧导航「记忆」。改动逐项自动保存，下一轮起生效。

---

## 关键概念

### 存档里的记忆分哪几类

游戏内「记忆」面板里能看到的条目分为：主线、当前目标、事实（GM 自动提取）、玩家笔记、固定记忆、能力、资源（物品、货币等）。每轮生成回复前，系统从这些类别里各取**最近的若干条**交给 GM，总量受 token 上限约束。

### 记忆桶

三个开关分别管三组类别：

- **固定记忆桶**：固定记忆。
- **世界记忆桶**：主线、当前目标、事实和玩家笔记。
- **角色记忆桶**：能力和资源。

关闭某个桶后，每轮的记忆注入里不再包含这一组。

### 自动事实的保留期

GM 自动提取的事实会越积越多。早于「事实保留回合数」的自动事实不再注入（只是不注入，不删除）；玩家笔记、固定记忆、能力、资源不受影响，永远不会因此被归档。系统每隔「归档检查间隔」个回合检查一次。

## 参数说明

### 记忆 · 召回行为

| 参数 | 含义 | 默认值 | 可调范围 |
|---|---|---|---|
| 每类记忆召回条数 | 事实、笔记、能力、资源、固定记忆每一类各取最近多少条交给 GM | 5 | 2–20 |
| 归档检查间隔 | 每隔多少回合检查一次有没有旧事实该归档 | 10 | 3–20 |
| 每轮注入记忆 token 上限 | 每轮交给 GM 的记忆总量上限（按字数估算 token），超出的条目这一轮不注入 | 800 | 200–2000（步进 50）|
| 事实保留回合数 | 早于这么多回合的自动事实不再注入 | 50 | 10–200（步进 5）|

召回条数和 token 上限共同决定最终注入量：条数调得再大，也不会超过 token 上限。

### 记忆 · 记忆桶配置

| 参数 | 含义 | 默认值 |
|---|---|---|
| 固定记忆条数上限 | 在记忆面板里最多能添加多少条固定记忆（5–100），到上限后要先删掉旧的才能再加 | 20 |
| 启用固定记忆桶 | 关闭后每轮的记忆注入里不再包含固定记忆 | 开启 |
| 启用世界记忆桶 | 关闭后每轮的记忆注入里不再包含主线、当前目标、事实和玩家笔记 | 开启 |
| 启用角色记忆桶 | 关闭后每轮的记忆注入里不再包含能力和资源 | 开启 |

## 常见任务

### 调整召回条数或 token 上限

1. 进入「设置 → 记忆」，在「记忆 · 召回行为」组找到目标参数。
2. 拖动滑块，或直接在右侧数字框输入数值。
3. 松开滑块（或数字框失去焦点）后自动保存，无需额外点击保存按钮。

### 关闭某个记忆桶

1. 在「记忆 · 记忆桶配置」区域找到对应开关（如「启用世界记忆桶」）。
2. 点击开关切换为「已禁用」，下一轮起生效。

### 调整固定记忆条数上限

1. 在「记忆 · 记忆桶配置」找到「固定记忆条数上限」数字框。
2. 输入新数值（5–100），失去焦点后自动保存。

> 上限调小后，已有的固定记忆不会被删除；只是在条数降到上限以下之前，记忆面板里不能再添加新的。

## 参数调整建议

### 剧情早期（记忆量少）

默认设置（每类 5 条、token 上限 800）对大多数对话已够用，无需调整。

### 剧情中后期（记忆积累多）

- 提高每类召回条数（8–12），让 GM 看到每一类里更多的近期条目。
- 提高 token 上限（1000–1500），容纳更多条目。
- 降低事实保留回合数（30–40），让过旧的自动事实更早退出注入。

### 节省 API 费用

- 降低 token 上限（400–600），是最直接减少每轮消耗的方式。
- 关闭用不到的记忆桶，例如不需要能力 / 资源时可以关闭「启用角色记忆桶」。

## 常见问题

**Q: GM 总是忘记某个重要设定，怎么办？**
A: 在游戏内侧栏「记忆」面板把它加为固定记忆，或写成玩家笔记（与自动事实冲突时以笔记为准）。如果条目很多，同时调高「每类记忆召回条数」和 token 上限。详见[游戏·记忆面板](/game-memory)。

**Q: 召回条数调太大有什么副作用？**
A: 每轮注入的 token 数量增加，API 费用上升，且更容易碰到 token 上限，超出的条目这一轮就不注入了。建议先调高 token 上限，再调大召回条数。

**Q: 自动事实过了保留期之后内容消失了吗？**
A: 没有。它们仍在存档里，只是不再每轮注入给 GM。

**Q: 「归档检查间隔」调大有什么效果？**
A: 检查得更少，过了保留期的旧事实会晚几回合才退出注入。一般不需要调整。

**Q: token 上限和模型上下文窗口有什么关系？**
A: 「每轮注入记忆 token 上限」只控制记忆部分的体积。整体上下文窗口（含历史对话、系统提示等）在「模型参数」页配置，记忆上限不能超过整体上下文的总额度。
